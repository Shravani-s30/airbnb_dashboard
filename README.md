# Airbnb Global Market & Performance Analytics | Power BI Dashboard

An interactive Power BI dashboard that analyses Airbnb listings across 10 cities to understand pricing, host performance, and guest reviews.

## Dataset

[Maven Analytics Data Playground - Airbnb Listings & Reviews](https://mavenanalytics.io/data-playground/airbnb-listings-reviews)

- 279K+ listings
- 182K+ hosts
- 5.3M+ reviews
- 10 cities

## Tools Used

Power BI, Power Query, DAX, Excel

## What I Did

- Cleaned the data in Power Query (removed duplicates, fixed missing values and data types)
- Built DAX measures for total listings, total hosts, average price, and average rating
- Designed an interactive dashboard with filters by city and room type
